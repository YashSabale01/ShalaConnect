DevOps CI/CD & Configuration Lifecycle

Automated Workflow

Continuous configuration flow implemented for ShalaConnect Spring Boot Backend (shalaconnect-backend-1.0.0.jar) using Git, Maven, Jenkins, Ansible, systemd, and Nginx.

01

Code & SCM

Developers commit Java Spring Boot source code to GitHub repository with semantic tagging.

git push origin main
02

Continuous Integration & Build

Jenkins webhook compiles bytecode, runs JUnit tests, and packages the Spring Boot executable fat JAR.

mvn clean package -DskipTests=false
03

Ansible Configuration Management

Ansible Control Node provisions EC2 servers with OpenJDK 21, sets up appuser, deploys the JAR, templates environment configs, and handles systemd daemons.

ansible-playbook playbooks/site.yml
04

Process & Reverse Proxy

Nginx proxies public port 80 traffic to Spring Boot application listening on port 8080, managed by Linux systemd.

systemctl status shalaconnect
05

Automated Verification & Monitoring

Ansible playbook verifies /api/health HTTP 200 status code and CloudWatch telemetry.

ansible uri: url=http://localhost:8080/api/health
